# Auto Typer 0.3

Voice preview, live captions and AI summaries join the main x64 app.

## New features

- **Local voice preview:** choose microphone and headphone devices, adjust Depth and Body, and compare with your original voice. This previews audio through your output device; it does not provide a virtual microphone to other apps.
- **Live English captions:** a pinnable overlay captions system audio, with optional microphone input labeled separately as System and Mic. Labels identify audio sources, not individual people. Recognition runs locally after a one-time English model download (about 41 MB).
- **Caption translation:** translate only new captions since your last successful translation using Microsoft Translator. Results appear in the main input.
- **Groq summaries:** expandable panels beside the main input and captions preserve the original text. Configure a primary and optional secondary Groq key for quota fallback.
- **General settings:** System, Dark and Light themes, run on startup, minimize to tray, separate single/double-click tray actions, and encrypted settings export/import including API keys.
- Clearer voice preview start/stop states, a minimum window width that keeps actions visible, and a simpler caption overlay.

Translation and summaries require your own API keys and send text only when requested. Voice processing and caption recognition run locally. Existing typing, screenshots, QR scanning, offline English OCR, R2 sharing and global hotkeys remain available.
