Clipboard translation, a sixth global shortcut, and portable encrypted settings backups are now available in the recommended app.

- **[AutoTyper.exe — recommended](https://github.com/santa512/AutoTyper/releases/download/v0.2.1/AutoTyper.exe)**: the complete app with typing, screen tools, offline English OCR, sharing, translation and tray mode.
- **[AutoTyperCompact.exe — lighter version](https://github.com/santa512/AutoTyper/releases/download/v0.2.1/AutoTyperCompact.exe)**: the smaller typing-focused app. Its features are unchanged; version metadata is updated to 0.2.1.

## What's new

- **Microsoft Translator clipboard translation:** English by default, with a target-language dropdown. The original text and translation appear together in the input. Optional clipboard copying and Stop cancellation are supported. Configure your own API key and Azure region in Settings → Translation; the button and global shortcut remain disabled until configured. The key is encrypted locally for your Windows account. Existing Gemini credentials are not reused.
- **Instant translate hotkey:** Ctrl+Shift+T by default. Change it in Settings → Hotkeys. Translation brings the window forward, including from tray mode. Existing preferences gain a conflict-free translation shortcut without losing previous bindings.
- **Settings export/import:** Settings → Export / Import saves typing preferences, all six hotkeys, Cloudflare configuration and both R2 keys, and Microsoft Translator configuration and key in a password-encrypted `.autotyper` file. Import on another PC with the same password, review the loaded settings, and Save to apply. Back can discard the import. Backups use AES-256-GCM with a password-derived key; keep the password because it cannot be recovered.
- **Layout fixes:** matching language-dropdown and translate-button heights; remove the empty space after Hotkeys.
- **Download page:** sizes use MB and KB, with the recommended app first and Compact as a lighter option.

## Upgrading

Choose Exit in the old app's tray menu before opening this version. Closing a tray-enabled window only hides it. Compatible saved settings and share history are retained. Clipboard translation sends text to Microsoft only when requested and requires internet access and API quota; QR and English OCR remain local. Settings backups include credentials but do not include input text or URL history.

The executables are unsigned. Verify downloads using their matching checksums.
