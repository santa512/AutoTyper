# Auto Typer 0.3.5

- Use scan-code key presses for characters supported by the active keyboard layout, improving compatibility with remote-desktop keyboard forwarding. Unicode fallback remains for other characters. Local and remote keyboard layouts should match; end-to-end Chrome Remote Desktop forwarding still requires validation in your session.
- Capture the application window focused after the countdown without requiring an accessible text field. Keep typing across controls in that window; pause when leaving and resume on return.
- Simplify controls to Start/Stop and separate Pause/Resume, remove Reset progress, and clearly show when typing is waiting for the original app.
- Remove the UI Automation/WPF dependency used by the previous field-level focus check.
- Preserve v0.3.4's Accurate/Fast caption modes, the faster base.en model and immediate caption cancellation.
