# Auto Typer 0.3.2

- Automatically pause when the original text input loses focus, including when returning to Auto Typer.
- Resume from the same typing progress when the original input regains focus. Pending typo corrections also wait safely.
- Track both the native control and Windows accessibility identity so a different field in the same window does not resume typing.
- Keep manual pause separate: returning to the input does not override a manual pause.

The destination must expose an accessible text input. Keep its caret and contents unchanged while paused; Auto Typer preserves its progress but does not restore a manually moved caret. If a field is replaced or closed, stop and start a new run.
