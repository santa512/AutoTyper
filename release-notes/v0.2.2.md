## What's new

- **ARM64:** both editions now run natively on Windows on Arm. The recommended app includes the same screen tools, offline English OCR, sharing and translation as x64. The OCR runtime is selected for the process architecture.
- **MSI setup:** installs for the current user under Local App Data, adds a Start menu shortcut, supports upgrades, and appears in Windows Installed apps for uninstalling. Preferences and API settings remain in your user profile. Portable EXEs remain available.
- **Run on startup:** enable Settings → Auto Typer → Run on startup and Save. It is off by default. Windows sign-in opens the app in the tray if Minimize to tray is enabled. Disabling the option removes the startup registration. Settings backups include this preference; importing and saving registers the EXE on the receiving PC.
- **Release checks:** native x64 and ARM64 builds run the feature tests, OCR fixtures, Compact engine tests, installer/uninstaller checks and checksum verification.

Choose Exit in the old tray menu before upgrading. Keep portable copies in a permanent folder if you enable startup; save the setting again after moving a copy. The installer removes its matching startup entry on uninstall. Existing compatible preferences and share history are retained.

The downloads are unsigned. Verify them using their matching checksums.
