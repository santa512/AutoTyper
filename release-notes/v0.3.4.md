# Auto Typer 0.3.4

- **Accurate captions now work as intended.** In 0.3.3 they could show only "…" because the speech model was slower than live speech. Accurate mode now uses Whisper `base.en`, which produces the same punctuated, capitalized captions about 1–2 seconds after the speaker pauses. A live preview grows while they talk.
- **Smaller download:** the Accurate model is now about 60 MB instead of 190 MB. The old model file is deleted once the new one has downloaded.
- **Instant stop and switch:** closing the caption overlay or switching between Accurate and Fast takes effect right away.

Captions still run entirely on your PC; no audio is uploaded. On older or low-power PCs the live preview refreshes less often. Switch to Fast if captions fall behind.
