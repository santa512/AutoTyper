# Auto Typer 0.1

The first release of Auto Typer for Windows x64.

## Download and run

Download **AutoTyper.exe** below and double-click it. No installer or separate .NET/Windows App SDK runtime installation is needed. Keep the executable named `AutoTyper.exe`; WinUI uses this name to find application resources. Bundled dependencies extract automatically on first launch.

The accompanying `AutoTyper.exe.sha256` file lets you verify the download with PowerShell's `Get-FileHash`.

## Included

- Global typing with adjustable pace and rhythm.
- A default 1% typo chance, including delayed corrections.
- A configurable global start/pause hotkey and ready countdown.
- Current-character highlighting in the locked input text.
- Compact progress/status, theme-matched title bar, and always-on-top pin.

## Usage notes

Focus the destination text field during the countdown, or start using the hotkey while it is already focused. Use a plain text editor for the most predictable result. Switching foreground windows stops typing. Enter and Tab keep the destination application's normal behavior. Apps running with higher privileges may reject simulated input.

This executable is unsigned. Windows may show a publisher or reputation prompt. Download from this repository's Releases page and verify the checksum.
