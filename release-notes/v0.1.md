# Auto Typer 0.1

Auto Typer for Windows x64, now available in two editions.

## Download and run

| Edition | Executable | What to choose |
| --- | --- | --- |
| **Compact** | `AutoTyperCompact.exe` | Small native Win32 window; under 1 MB, no bundled runtime or extraction. |
| **WinUI** | `AutoTyper.exe` | Original modern Windows interface; approximately 92 MB with runtimes included. |

Download either executable below and double-click it. Neither needs an installer. Keep the WinUI filename `AutoTyper.exe` so it can resolve its application resources; its bundled dependencies extract on first launch. Compact uses Windows system components directly. Run one edition at a time to avoid global-hotkey conflicts.

Each executable has a matching `.sha256` file for verification with PowerShell's `Get-FileHash`. The [download page](https://santa512.github.io/AutoTyper/#downloads) compares both editions.

## Included

- **Paste from clipboard** in both versions: load plain text into the input without starting typing. The button is disabled during a run.

- Global typing with adjustable pace and rhythm.
- A default 1% typo chance, including delayed corrections.
- A configurable global start/pause hotkey and ready countdown.
- Current-character highlighting in the locked input text.
- Compact progress/status, theme-matched title bar, and always-on-top pin.

Compact supports Ctrl/Alt/Shift hotkeys and whole-percent mistake settings; WinUI additionally supports Windows-key combinations and finer mistake adjustments. Both default to 1% mistakes and a 2.5-second ready delay. See the repository's `native/README.md` for the compact project's build instructions.

## Usage notes

Focus the destination text field during the countdown, or start using the hotkey while it is already focused. Use a plain text editor for the most predictable result. Switching foreground windows stops typing. Enter and Tab keep the destination application's normal behavior. Apps running with higher privileges may reject simulated input.

This executable is unsigned. Windows may show a publisher or reputation prompt. Download from this repository's Releases page and verify the checksum.
