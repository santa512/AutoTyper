# General settings (v0.3, main x64)

Open **Settings → General** for:

- **Run on startup:** start the current EXE at Windows sign-in. With tray mode enabled, it starts in the tray.
- **Minimize to tray:** keep the app running when minimized or closed. Use the tray menu's Exit command to quit.
- **Theme:** System, Dark or Light. Selection previews immediately across the main window and caption overlay; Save persists it. Back → No restores the previous theme.
- **Tray click / Tray double-click:** assign each gesture independently to the main window, tray menu, captions, typing, screenshot, instant share, QR, text extract, clipboard translation, settings or no action. Right-click always opens the tray menu. A single click waits for Windows' double-click interval so a double-click runs only its assigned action. Tool configuration and busy-state checks still apply.
- **Export / Import:** password-encrypted backups include theme, startup/tray preferences, both tray actions, typing settings, hotkeys and API settings/keys, including both Groq keys. Import loads values for review; Save applies them. Older preferences and backups default to System theme and opening the main window for either tray gesture.

General is the first section. Auto Typer retains pace, rhythm, mistake chance and delay; Cloudflare, Hotkeys and Translation retain their own sections. Save and Back stay fixed at the bottom.
